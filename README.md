# 가계부 대시보드

2026년 구글시트 가계부(연간요약/부업/월별)를 실시간으로 불러와 보여주는 정적 대시보드.
서버·백엔드 없음. 브라우저에서 로그인 후 Google Sheets API를 직접 호출.

## 배포 순서

### 1) Google Cloud OAuth 클라이언트 발급
1. https://console.cloud.google.com → 새 프로젝트 생성 (예: `bokhodu-budget-dashboard`)
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Sheets API` 검색 → **사용 설정**
3. **API 및 서비스 → OAuth 동의 화면**
   - User Type: **외부(External)** 선택 → 앱 이름/이메일만 입력하고 저장
   - 테스트 사용자에 본인 구글 계정 이메일 추가 (승인 안 받은 앱은 테스트 사용자만 로그인 가능)
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 자바스크립트 원본에 아래 두 개 추가
     - `https://<본인깃허브아이디>.github.io`
     - `http://localhost:5500` (로컬 테스트용, Live Server 포트에 맞게)
   - 만들기 → 발급된 **클라이언트 ID**를 `config.js`의 `CLIENT_ID`에 붙여넣기

### 2) 시트 공유 확인
이 대시보드는 로그인한 본인 계정으로 API를 호출하므로, 시트가 본인 소유거나 최소 "뷰어"로 공유돼 있으면 됨. 별도 공개 설정 불필요.

### 3) GitHub Pages 배포
```bash
git init
git add index.html app.js config.js README.md
git commit -m "가계부 대시보드 초기 배포"
git remote add origin https://github.com/<아이디>/<레포명>.git
git push -u origin main
```
그 다음 GitHub 저장소 → Settings → Pages → Branch: `main` / `/(root)` 선택 → 저장.
몇 분 뒤 `https://<아이디>.github.io/<레포명>/` 접속.

### 4) 접속 후
"Google로 로그인" → 시트 접근 동의 → 자동으로 연간요약/부업/1~8월 시트를 한 번에 읽어와 대시보드 렌더링.
새로고침 버튼으로 다시 동기화 (세션 캐시라 탭 닫으면 초기화됨).

## 구조
- `index.html` — 마크업 + 스타일
- `config.js` — 스프레드시트 ID / OAuth 클라이언트 ID / 시트명 매핑
- `app.js` — 인증, Sheets API 호출, 파싱, 차트 렌더링

## 파싱 로직 메모
- 셀 **좌표 하드코딩 대신 라벨 텍스트를 찾아서 상대 위치로 읽음** → 행 추가/삭제에 어느 정도 안전
- 연간요약 시트에 월별 총수입/총지출/저축 값이 있으면 그 값을 우선 사용, 없는 달(1~5월, 8월 등)은 해당 월 시트에서 직접 집계해서 대체
- 1~5월(구형 포맷): "분류/제목/금액" 한 테이블에 수입·지출·저축이 섞여 있어서 분류명으로 분리 (월급→수입, "저축"류→저축, 나머지→지출)
- 6~8월(신형 포맷): 상단 요약 블록 + 고정지출/변동지출 좌우 2단 테이블 구조를 그대로 파싱

## 앞으로 확장 아이디어
- 9~12월 자동 확장 (매달 `config.js` MONTHS 배열에 숫자만 추가)
- 자산 현황(부동산/금융자산) 탭 추가
- 카드 실적 추적(현대카드 이벤트 등) 별도 위젯
